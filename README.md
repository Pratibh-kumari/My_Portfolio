# Pratibha Kumari — Cybersecurity Portfolio

A responsive, dark-first portfolio built with vanilla HTML, CSS and JavaScript.

## Run locally

1. Extract the project folder.
2. Open it in VS Code.
3. Start `index.html` with the Live Server extension, or open the file directly in a browser.

No build step or npm dependencies are required.

## Project structure

```text
pratibha-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── favicon.svg
    └── resume.pdf
```

## Before publishing

- Verify the public contact email and profile URLs in `index.html`.
- Review internship status labels and update them when dates/status change.
- Add direct GitHub repository URLs to project cards once the repositories are public. No project repository URLs have been guessed.
- Replace `assets/resume.pdf` whenever you update your resume.
- Add project screenshots or a professional portrait if desired.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `portfolio`).
2. Upload all files and the `assets` folder, preserving the folder structure.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site will be published at `https://YOUR_USERNAME.github.io/portfolio/`.

## Features

- Responsive layout and mobile navigation
- Animated typing headline and reveal-on-scroll sections
- Project category filters
- Persistent dark/light theme toggle
- Scroll progress indicator
- Resume PDF link
- GitHub, LinkedIn, TryHackMe and email links
- Reduced-motion accessibility support
